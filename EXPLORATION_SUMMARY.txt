       ├─ korean: String (secondary, optional)
       ├─ startTime/endTime: Double?
       ├─ confidence: Double? (0-1)
       ├─ isAnchor: Bool (auto-set by alignment)
       ├─ isUserAnchor: Bool (user-set, locked)
       └─ manuallyAdjustedStart/End: Bool (track manual edits)

KEY INSIGHT: LyricBlock has rich state tracking for alignment quality
  - Confidence scoring enables user to spot problematic alignments
  - Anchor system (auto + user) enables piecewise correction
  - Manual adjustment flags track user overrides

DESIGN DECISIONS TO NOTE
================================================================================

1. NO EXTERNAL DEPENDENCIES FOR CORE FEATURES
   - SwiftUI, AVFoundation, Sparkle only
   - All processing via external tools (FFmpeg, whisper-cpp, Python)
   - Makes distribution simple, avoids dependency hell

2. FRAME-BY-FRAME BURN-IN (NOT FFMPEG)
   - Stage 1: FFmpeg crops/scales/trims
   - Stage 2: Custom AVAssetReader/Writer for subtitle overlay
   - Ensures precise timing, pixel-perfect rendering
   - Slower than pure FFmpeg but more flexible

3. DUAL ALIGNMENT MODES
   - Production: whisper-cpp segment matching (built-in, recommended)
   - Experimental: Python pipelines (optional, A/B testing)
   - Isolated from production output

4. MACOS ONLY
   - Uses AppKit features (NSApplicationDelegate, NSOpenPanel, NSTextView)
   - AVPlayerLayer for native video playback
   - Not portable to iOS without major refactoring

5. BACKWARD COMPATIBILITY FIRST
   - All Codable models have custom init(from:) decoders
   - Missing fields get sensible defaults
   - Old project files load without errors

6. USER CONTROL OVER AUTOMATION
   - Alignment produces best-guess timings
   - All timings can be manually overridden
   - Manual edits preserve anchor system
   - Preview shows exact output (WYSIWYG)
